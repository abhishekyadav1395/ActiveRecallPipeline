PART 2 — QUESTION LAYERS
══════════════════════════════════
Generate in sequence. Exhaust each layer before the next.
Generate as many as the concept genuinely supports. Never force. Never cap.

LAYER 1 — FOUNDATION   (concepts tagged source:decomposition)
  Tests prerequisite knowledge. Tag: Level::Foundation

LAYER 2 — SURFACE
  Tests what the text explicitly states. Tag: Level::Surface

LAYER 3 — REASONING
  Tests why, how, context, significance. Tag: Level::Reasoning

LAYER 4 — BOUNDARY
  Tests what the concept IS NOT.
  MANDATORY for every Boundary question:
  - At least one statement must be true of a NEIGHBOURING concept
    and false for THIS concept — never statements all about the same concept
  - State explicitly in the answer explanation which neighbouring concept
    the distractor statement is borrowed from
  - The student must know TWO concepts to answer correctly
  Use Format B only. Tag: Level::Boundary

LAYER 5 — ORDERING
  Only when genuine sequence exists. Tag: Level::Ordering

LAYER 6 — LINEAGE
  Only after layers 1-5 exhausted.

  Generate a Lineage question whenever ANY of these are true:
  - The concept names a specific source it was derived from
  - The concept names an earlier version of itself that evolved
  - The concept names a predecessor document, law, theory,
    or institution it replaced or built upon
  - The text uses words like "borrowed from", "derived from",
    "inspired by", "based on", "modelled on", "adopted from",
    "evolved from", "replaced", "successor to", "origin of"

  These are all triggers for Lineage — do not skip them.

  MANDATORY structure for every Lineage question:
  - Ask which source, predecessor, or origin the concept
    traces back to
  - Wrong options must be other plausible sources —
    never vague descriptions
  - Answer must name the ancestor precisely

  Tag: Level::Lineage
  {{LINEAGE_GUIDANCE}}

PART 3 — QUESTION FORMATS
══════════════════════════════════
FORMAT A — DIRECT MCQ
  [Question stem]
  (A) option  (B) option  (C) option  (D) option
  Use for: single facts, definitions, dates, Layer 1 Foundation

FORMAT B — STATEMENT-BASED MCQ
  Consider the following statements about [concept]:
  1. [statement]   2. [statement]   3. [optional]
  Which of the above statements is/are correct?
  (A)... (B)... (C)... (D)...
  Rules: 2-3 statements. Never all correct or all wrong.
  MANDATORY: at least one statement true of a neighbouring concept.
  Use for: Layer 4 Boundary, multi-property, comparisons, multi-clause

FORMAT C — ORDERING MCQ
  Arrange the following in [chronological/sequential] order:
  1.[item] 2.[item] 3.[item] 4.[item]
  Max 4 items. Answer must state actual years/markers. Layer 5 only.

══════════════════════════════════
PART 4 — DISTRACTOR ARCHETYPES
══════════════════════════════════
NEAR MISS — correct in almost every way, wrong in one precise detail
CORRECT CONCEPT WRONG CONTEXT — true of related concept, wrong here
  MANDATORY in every Format B question
REVERSAL — properties or cause/effect pair are swapped
ATTRACTIVE CONFUSION — sounds similar, commonly confused

DISTRACTOR HARDNESS TEST — apply before finalising every option:
Ask: "Can a student eliminate this option using common sense alone
without any subject knowledge?" If YES — replace it.

Every wrong option must reference a real entity:
a real provision, real number, real case, real document,
real theory, or real historical event relevant to the subject.
Never use vague descriptions as distractors.
Wrong: "A law that is not properly documented"
Correct: "Section 107 of the Government of India Act 1935"

All distractors must require genuine subject knowledge to eliminate.
